MeetingRecorder — Windows 11 向け ポータブル会議録音・リアルタイム文字起こしアプリ
=====================================================================================

■ 使い方（インストール不要）
  1. この ZIP を任意のフォルダーに展開します。
     （例: C:\Users\<ユーザー名>\Tools\MeetingRecorder\）
  2. MeetingRecorder.exe をダブルクリックして起動します。
  3. 初回のみ、マイク／PC内部音声の取得元／保存先を設定します。
  4. 「録音開始」を押すと、マイクとPC内部音声の両方の録音が始まります。

  管理者権限は不要です。.NET / Python / Node.js / Visual C++ ランタイムの
  事前インストールも不要です（自己完結型ビルド）。

■ SmartScreen の警告について
  署名されていない実行ファイルのため、初回起動時に
  「Windows によって PC が保護されました」と表示されることがあります。
  「詳細情報」→「実行」で起動できます。組織のポリシーで実行できない場合は
  情報システム部門にご相談ください。

■ プライバシー
  会議の音声・文字起こし・議事録が外部へ送信されることは一切ありません。
  クラウドAI／クラウド音声認識APIは使用していません。
  外部通信は「AIモデルの初回ダウンロード」時のみ発生します（ユーザーの明示操作が必要）。
  利用状況の送信、クラッシュレポートの自動送信などのテレメトリーはありません。

■ AIモデルについて
  文字起こしには whisper.cpp のモデル（MIT ライセンス）を使用します。
  モデル本体はこの ZIP に含まれていません。設定画面または初回設定ウィザードから
  ダウンロードしてください（モデル名・配布元・サイズ・保存先・ライセンスを事前に表示します）。
  モデルを取得しなくても「録音」は利用できます（文字起こしのみ行われません）。

■ 保存されるもの
  会議ごとに次のフォルダーが作成されます。
      2026-09-07_1430_Meeting\
        meeting.wav  （または meeting.mp3）
        transcript.txt / transcript.md
        minutes.txt / minutes.md   ← 「議事録を生成」を実行した場合
        metadata.json

■ 動作環境
  Windows 11（Windows 10 でも動作します） / x64
  推奨: 4コア以上のCPU、RAM 8GB以上、空きディスク 2GB以上
  基準環境: Core i5-1335U / RAM 16GB / 内蔵GPU（NVIDIA GPU 不要）
